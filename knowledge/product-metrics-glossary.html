Product Metrics Glossary

Owner: Vyshnav (Product Lead). Source of truth: BigQuery dataset tensor.product_metrics (daily).

  • Daily active users (DAU): distinct users with at least one authenticated session in the day (IST).
  • Weekly active users (WAU): distinct users active in the trailing 7 days.
  • Payment success rate: successful payments divided by attempted payments, excluding user cancellations.
  • API p95 latency: 95th percentile gateway latency in milliseconds for the payments API.
  • Support tickets: new customer support tickets opened that day.

Targets for Q4 2026: payment success rate at least 98.5%, API p95 latency under 250 ms.
