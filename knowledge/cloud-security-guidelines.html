Cloud Security Guidelines

Document ID: SEC-POL-001 · Version 4.2 · Owner: David Mathew (Security Lead) · Effective: 1 July 2026 · Applies to all production systems of Acme Fintech Pvt Ltd.

1. Encryption

  • SEC-1.1 Encryption in transit: All external and internal service endpoints MUST use TLS 1.2 or higher. TLS 1.0 and TLS 1.1 are prohibited, including for legacy partner integrations. Exceptions require written approval from the Security Lead and expire after 30 days.
  • SEC-1.2 Encryption at rest: All customer data stores MUST use customer-managed encryption keys (CMEK) in Cloud KMS. Google-managed default keys are not sufficient for customer data.
  • SEC-1.3 Key rotation: CMEK keys rotate automatically every 90 days.

2. Identity and access

  • SEC-2.1 Service authentication: Service-to-service calls use OAuth 2.0 client credentials or Workload Identity. Static API keys are prohibited for production traffic.
  • SEC-2.2 Token lifetime: Access tokens MUST expire within 60 minutes. Refresh tokens MUST rotate on every use and expire within 24 hours of inactivity (see ADR-007).
  • SEC-2.3 Human access: Production console access requires MFA and just-in-time elevation. Standing admin roles are prohibited.

3. API protection

  • SEC-3.1 Rate limiting: Every public API MUST enforce per-client rate limiting at the API gateway (default 100 requests per second per client, burst 200; see ADR-012).
  • SEC-3.2 Input validation: Request schemas are validated at the gateway; payloads over 1 MB are rejected unless an endpoint is explicitly configured.

4. Logging and retention

  • SEC-4.1 Audit logs: Security and access audit logs MUST be retained for at least 365 days in an immutable log bucket.
  • SEC-4.2 Application logs: Application logs are retained for 90 days and MUST NOT contain card numbers, Aadhaar numbers or passwords.

5. Data residency

  • SEC-5.1: Customer personal data MUST be stored and processed only in India regions (asia-south1 Mumbai or asia-south2 Delhi). Backups follow the same rule.

6. Vendors

  • SEC-6.1: Vendors processing customer data must hold ISO 27001 or SOC 2 Type II certification and meet the Vendor SLA Standard (VEN-POL-003).
