ADR-007: OAuth 2.0 with refresh-token rotation for the API gateway

Status: Accepted · Date: 12 February 2026 · Deciders: David Mathew, Rahul Verma · Related: SEC-POL-001 section 2.

Context

The payments API gateway used long-lived static API keys for partner access. A leaked key in March 2025 allowed unauthorized reads for 11 days before detection.

Decision

  • All partner and internal clients authenticate with OAuth 2.0 (client credentials for services, authorization code with PKCE for apps).
  • Access tokens expire after 60 minutes.
  • Refresh tokens rotate on every use; reuse of an old refresh token revokes the whole token family.
  • Token issuance and revocation events are written to the security audit log (365-day retention).

Consequences

Partners must update client libraries. The legacy static-key path is removed after 30 June 2026. Rotation adds roughly 2 ms per token refresh at the gateway.
