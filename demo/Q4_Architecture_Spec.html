Q4 Architecture Spec: Payments API v3

Prepared by: Platform team (Rahul Verma) · Vendor partner: FastPay Gateway Ltd · Draft 0.9 · 9 October 2026 · Confidential

1. Overview

Payments API v3 replaces the v2 gateway for card and UPI payments. It moves partner traffic to the new API gateway, adds the FastPay Gateway processor for UPI, and consolidates logging into a single pipeline. Target launch: 15 December 2026.

2. Authentication and authorization

  • All partners authenticate with OAuth 2.0 client credentials issued by the Acme auth service.
  • Access tokens expire after 60 minutes. Refresh tokens rotate on every use.
  • Internal services use Workload Identity; no static keys in production.

4. API protection

  • Per-client token-bucket rate limiting at the gateway: 100 requests per second, burst 200; HTTP 429 with Retry-After.
  • Request payloads limited to 1 MB.

5. Data storage and residency

  • Payment records in Cloud Spanner, asia-south1, encrypted with CMEK keys rotated every 90 days.
  • Daily backups to asia-south2.
